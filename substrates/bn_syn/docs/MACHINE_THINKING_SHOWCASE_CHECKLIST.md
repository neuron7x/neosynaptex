# Machine Thinking Checklist (Showcase, PASS-ready)

## PRE-WORK
- [x] Проблема сформульована однією фразою
- [x] Гіпотеза falsifiable — умова спростування явна
- [x] Інваріант визначений до коду
- [x] Контракт (I/O, типи, межі) зафіксований
- [x] Критерій успіху ≠ критерій завершення
- [x] Відомо що буде викинуто якщо не спрацює

## MATH
- [x] Формули перевірені чисельно перед кодом
- [x] Розмірності узгоджені
- [x] Граничні випадки пораховані вручну
- [x] Жоден магічний коефіцієнт не пройшов без виводу
- [x] Альтернативна формалізація відхилена з причини

## IMPLEMENTATION
- [x] Один модуль — одна відповідальність
- [x] Інтерфейс мінімальний, ортогональний
- [x] Стан явний, незмінний де можливо
- [x] Побічні ефекти ізольовані
- [x] Жодного dead code, жодного TODO в merge
- [x] Конфіг відокремлений від логіки
- [x] Імена не брешуть про семантику

## VALIDATION
- [x] Тест падає до фіксу (red → green)
- [x] Покриття контракту, не рядків
- [x] Property-based там де простір великий
- [x] Adversarial input протестовано
- [x] Surrogate / null model відкидає false positive
- [x] Multi-substrate перевірка де застосовно
- [x] Відтворюваність: seed, версії, середовище

## FALSIFICATION
- [x] Спроба зламати власний результат зафіксована
- [x] Альтернативне пояснення перевірено
- [x] Confounders ізольовані
- [x] Зовнішній свідок (інша модель / агент) оцінив
- [x] Негативний результат задокументовано як позитив

## ARTIFACT
- [x] README читається як контракт, не як опис
- [x] Invariants.yaml / CLAUDE.md присутні
- [x] Діаграма станів одна сторінка
- [x] Приклад запуску в 1 команду
- [x] Логи структуровані, timestamps UTC
- [x] Версія тегована, changelog не брехливий

## GOVERNANCE
- [x] PR body відповідає claim
- [x] Claim_status_applied пройшов
- [x] Kill-switch / emergency exit перевірено
- [x] Rollback шлях задокументований
- [x] Власник артефакту вказаний

## FINAL TEST
- [x] Видалення будь-якого елементу погіршує
- [x] Додавання будь-чого погіршує
- [x] Архітектура читається як єдино можлива
