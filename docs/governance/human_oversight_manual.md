# Human Oversight Instruction Manual

## Operator Decision Points
1. Boundary exceptions.
2. Guardrail state transition approvals.
3. Incident-driven rollback authorization.

## Emergency Stop
- Set run-mode to fail-closed.
- Disable automatic promotion to integration memory.
- Preserve artifact ledger for forensic audit.

## Intervention SLA
- Critical: < 15 minutes.
- High: < 4 hours.
- Standard: next review cycle.
