# Data Quality Assessment (DQA)

## Dataset Scope
Calibration datasets under `data/eai_calibration/`.

## Quality Dimensions
- Completeness: required fields present.
- Representativeness: includes contradiction and normal cases.
- Accuracy: schema-valid and parseable JSONL records.
- Consistency: deterministic labels for baseline claims.

## Current Status
- Baseline only; not statistically representative for production use.
