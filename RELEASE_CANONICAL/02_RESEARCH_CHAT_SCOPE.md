## What cannot be restored from this GitHub connector

- Verbatim ChatGPT turn-by-turn text or unseen prior messages.
- Attachments uploaded only in ChatGPT, prior drafts not checked into Git, or older unrelated projects.
- Private chat content that would cause unintended disclosure in this **public** repository.

For a complete verbatim transcript, export ChatGPT data separately from the account; handle the export privately. An independently built private archival ZIP can incorporate that export with the existing source snapshot later.

**Do not present this reconstruction as 100% of the user's chat messages.** The public release covers all tracked GitHub source at the frozen snapshot but only the research-relevant reconstructable chat context.
